# ADR-0002: src-layout monorepo and specification files in repository root

**Date:** 2026-08-20  
**Status:** Accepted  
**Milestone:** M0

## Context

Master spec §5 prescribes a Python monorepo with `src/sports_intelligence/`.
`README_EXECUTION_ORDER.md` allows the specification `.md` files to live in the
repo root or a `spec/` directory.

## Decision

1. Use the `src/` layout with the import package `sports_intelligence`.
2. Keep all specification `.md` files (`00_*` … `20_*`, `PACK_MANIFEST.md`,
   `README_EXECUTION_ORDER.md`, `AGENTS.md`) in the repository root. They were
   authored with root-relative cross-references and moving them would require
   touching many references for no functional gain.

## Alternatives

- Flat package layout — rejected: `src/` isolates the package from test/CI
  tooling and accidental imports.
- `spec/` directory — rejected for now to avoid churn in existing references.

## Consequences

- Clean separation between importable code and project docs.
- Reviewers read specs from the root; docs generated by the implementation
  live under `docs/`.

## Rollback/Migration

Moving specs into `spec/` later is mechanical (one move + reference updates).
